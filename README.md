# Shynli Deep Cleaning

Standalone Vite / React site for `shynlideepcleaning.com`.

## Production

- Domain: `https://shynlideepcleaning.com`
- Lead destination: `https://shynlicleaningservice.com/quote`
- Sitemap: `https://shynlideepcleaning.com/sitemap.xml`
- Robots: `https://shynlideepcleaning.com/robots.txt`

## Deploy

Render Static Site:

- Build command: `npm ci && npm run build`
- Publish directory: `dist`
- Custom domains: `shynlideepcleaning.com`, `www.shynlideepcleaning.com`

## Local Check

```bash
npm ci
npm run lint
npm run build
```
